# Proxmox DevOps Homelab

A practical infrastructure and DevOps learning environment built using Proxmox VE and virtual machines.

## Projects

1. [Proxmox Infrastructure](01-proxmox-infrastructure/)
2. [Linux Administration](02-linux-administration/)
3. [Networking](03-networking/)
4. [Ansible Automation](04-ansible-automation/)
5. [Docker and Docker Compose](05-docker-and-compose/)
6. [Kubernetes](06-kubernetes/)
7. [Monitoring and Observability](07-monitoring-and-observability/)
8. [CI/CD and GitOps](08-cicd-and-gitops/)
9. [Hybrid Cloud and AWS](09-hybrid-cloud-aws/)

## Objectives

- Develop practical Linux and infrastructure administration skills.
- Learn networking and virtualisation.
- Automate infrastructure using Ansible.
- Deploy and manage containerised applications.
- Build and operate Kubernetes clusters.
- Implement monitoring, observability and CI/CD.
- Explore hybrid cloud infrastructure.

## Approach

Each project includes its objectives, architecture, implementation, configuration examples, troubleshooting notes and lessons learned.

## Environment

- Hypervisor: Proxmox VE
- Virtual machines: Ubuntu Server
- Automation: Ansible
- Containerisation: Docker and Docker Compose
- Version control: Git and GitHub

More technologies will be added as the lab evolves.
